# Task: Identity UI Scaffolding

## Description
Use ASP.NET Core Identity scaffolding to generate login, register, and account management pages. Customize the generated Razor pages to match the existing Tailwind CSS design system.

## Acceptance Criteria
- [ ] Identity UI scaffolded with required pages (Login, Register, Manage, Logout)
- [ ] Generated pages integrated with existing layout
- [ ] Tailwind CSS classes applied to match existing design
- [ ] Form validation working correctly
- [ ] Email confirmation page created (even if email not configured yet)
- [ ] Password reset pages created

## Technical Details
- **Scaffold command**:
  ```bash
  dotnet aspnet-codegenerator identity -dc PromptManagerContext --files "Account.Login;Account.Register;Account.Logout;Account.Manage.Index"
  ```
- **Files created**:
  - `Areas/Identity/Pages/Account/*.cshtml` (multiple pages)
  - Update existing `_LoginPartial.cshtml` or create new
- **Styling approach**: Replace Bootstrap classes with Tailwind equivalents
- **Integration points**: Ensure pages use existing MainLayout

- [ ] Scaffolding tool must be installed
