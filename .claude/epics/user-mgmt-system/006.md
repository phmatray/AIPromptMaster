# Task 006: UI Auth Components - Add LoginDisplay and update MainLayout with auth state

## Description

Create authentication-aware UI components including a LoginDisplay component for the navigation bar and update the MainLayout to show user authentication state. This task provides users with login/logout functionality and displays the current user's information in the application header.

## Acceptance Criteria

- [ ] LoginDisplay component created with login/logout functionality
- [ ] MainLayout updated to include LoginDisplay in navigation
- [ ] User menu dropdown shows user information and logout option
- [ ] Login/Register/Logout links navigate to appropriate Identity pages
- [ ] Authentication state visually represented throughout the application
- [ ] Responsive design maintained across different screen sizes
- [ ] Component styling matches existing application theme
- [ ] Proper accessibility attributes for auth-related UI elements

## Technical Details

### LoginDisplay Component
```razor
@using Microsoft.AspNetCore.Identity
@inject SignInManager<IdentityUser> SignInManager
@inject UserManager<IdentityUser> UserManager

<AuthorizeView>
    <Authorized>
        <div class="dropdown">
            <button class="btn dropdown-toggle" type="button" data-bs-toggle="dropdown">
                Welcome, @context.User.Identity?.Name!
            </button>
            <ul class="dropdown-menu">
                <li><a class="dropdown-item" href="/Identity/Account/Manage">Profile</a></li>
                <li><hr class="dropdown-divider"></li>
                <li>
                    <form method="post" action="/Identity/Account/Logout">
                        <button type="submit" class="dropdown-item">Logout</button>
                    </form>
                </li>
            </ul>
        </div>
    </Authorized>
    <NotAuthorized>
        <a class="btn btn-primary" href="/Identity/Account/Login">Login</a>
        <a class="btn btn-outline-primary" href="/Identity/Account/Register">Register</a>
    </NotAuthorized>
</AuthorizeView>
```

### MainLayout Updates
