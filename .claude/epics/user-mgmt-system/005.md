# Task 005: Prompt Authorization - Update PromptService to filter by authenticated user

## Description

Implement user-based authorization in the PromptService to ensure users can only access their own prompts. This includes updating all CRUD operations to filter by the authenticated user's ID and adding authorization attributes to sensitive operations.

## Acceptance Criteria

- [ ] PromptService injects IHttpContextAccessor to access current user
- [ ] All GetPrompts methods filter by current user's ID
- [ ] Create operations automatically set UserId from current user
- [ ] Update/Delete operations verify ownership before proceeding
- [ ] Authorization attributes protect sensitive service methods
- [ ] Non-owned prompts are inaccessible to unauthorized users
- [ ] Service methods throw appropriate exceptions for unauthorized access
- [ ] Existing functionality works correctly for authorized operations

## Technical Details

### Service Injection Updates
```csharp
public class PromptService : IPromptService
{
    private readonly IHttpContextAccessor _httpContextAccessor;
    
    public PromptService(PromptManagerContext context, IHttpContextAccessor httpContextAccessor)
    {
        _context = context;
        _httpContextAccessor = httpContextAccessor;
    }
    
    private string GetCurrentUserId()
    {
        return _httpContextAccessor.HttpContext?.User?.FindFirstValue(ClaimTypes.NameIdentifier)
            ?? throw new UnauthorizedAccessException("User not authenticated");
    }
}
```

### Method Updates
- **GetAllPromptsAsync**: Filter by `UserId == currentUserId`
- **GetPromptByIdAsync**: Verify ownership before returning
- **CreatePromptAsync**: Automatically set `prompt.UserId = currentUserId`
- **UpdatePromptAsync**: Verify ownership before updating
- **DeletePromptAsync**: Verify ownership before deleting
- **SearchPromptsAsync**: Filter results by current user

### Error Handling
- Throw `UnauthorizedAccessException` for ownership violations
- Return appropriate HTTP status codes via controllers
- Log security-related access attempts
