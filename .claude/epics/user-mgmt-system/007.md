# Task 007: User Profile Service

## Description

Create a comprehensive user profile service to handle user profile management operations including profile updates, preferences, and user-specific data management. This service will follow the existing service layer pattern and provide a clean interface for user profile operations.

## Acceptance Criteria

- [ ] IUserService interface created with all necessary profile operations
- [ ] UserService implementation following existing service patterns
- [ ] Profile update operations with validation
- [ ] User preferences management (theme, notifications, etc.)
- [ ] Profile picture handling (placeholder for future file upload)
- [ ] Service registered in DI container
- [ ] Error handling and validation following application standards
- [ ] Unit tests for service methods (when test infrastructure exists)

## Technical Details

### Service Interface (IUserService)
```csharp
public interface IUserService
{
    Task<ApplicationUser?> GetUserProfileAsync(string userId);
    Task<bool> UpdateUserProfileAsync(string userId, UserProfileUpdateModel model);
    Task<UserPreferences> GetUserPreferencesAsync(string userId);
    Task<bool> UpdateUserPreferencesAsync(string userId, UserPreferences preferences);
    Task<bool> ChangePasswordAsync(string userId, string currentPassword, string newPassword);
    Task<bool> UpdateEmailAsync(string userId, string newEmail);
    Task<IEnumerable<ApplicationUser>> GetAllUsersAsync(); // Admin only
    Task<bool> DeleteUserAsync(string userId); // Admin only
}
```

### User Preferences Model
```csharp
public class UserPreferences
{
    public string Theme { get; set; } = "light"; // light, dark, auto
    public bool EmailNotifications { get; set; } = true;
    public bool ShowTutorials { get; set; } = true;
    public int PageSize { get; set; } = 10;
    public string TimeZone { get; set; } = "UTC";
}
```

### Profile Update Model
```csharp
public class UserProfileUpdateModel
{
    [Required, StringLength(100)]
    public string FirstName { get; set; } = string.Empty;
    
    [Required, StringLength(100)]
    public string LastName { get; set; } = string.Empty;
    
    [StringLength(500)]
    public string? Bio { get; set; }
    
    [StringLength(100)]
    public string? JobTitle { get; set; }
    
    [StringLength(100)]
    public string? Company { get; set; }
}
```

### Implementation Requirements
- Follow existing service pattern (similar to PromptService)
- Use UserManager<ApplicationUser> for user operations
- Implement proper error handling and logging

### Database Changes
- Add UserPreferences column to AspNetUsers table
- Add profile fields (Bio, JobTitle, Company) to ApplicationUser
- Create migration for new columns
